Один клик по кнопке скорости теперь меняет скорость только этого видео — и ничего больше.

Раньше, если была включена память по каналам, тот же клик заодно записывал скорость за каналом: замедлить одно видео, не меняя настройку канала, было невозможно. Теперь это две разные вещи. Скорость для канала сохраняется отдельной кнопкой на панели — рядом с закладкой «по умолчанию везде». Кнопка горит, пока у канала есть своя скорость; нажать ещё раз — снять. Она же включает саму функцию, так что искать её в настройках больше не нужно.

Исправлена и панель: при выбранном положении «ползунок справа» одна лишняя кнопка скорости отправляла ползунок и шестерёнку на вторую строку. Теперь переносятся сами кнопки скорости, а ползунок и значки остаются справа, как и выбрано.

A single click on a speed button now changes the speed of that video only — and nothing else.

Previously, with per-channel memory enabled, the same click also stored the speed for the channel, so slowing down one video without changing the channel's setting was impossible. These are two separate things now. Saving a speed for a channel has its own button on the panel, next to the "default everywhere" bookmark. It stays lit while the channel has its own speed; press it again to clear. It also switches the feature on, so there is no need to hunt for it in the settings.

The panel is fixed too: with the slider set to the right, one extra speed button used to push the slider and the gear onto a second line. Now the speed buttons themselves wrap and the slider and icons keep their place on the right.
