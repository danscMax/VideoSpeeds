Память скорости для каждого канала YouTube наконец опознаёт канал во всех случаях.

Расширение определяет канал по ссылке на автора под видео. Оно понимало только короткую форму ссылки — а если другое дополнение переписывало её в полную («https://www.youtube.com/@канал/videos»), канал не опознавался и функция не работала вообще: сохранённая скорость не применялась, новые нажатия не запоминались. Теперь ссылка разбирается по-настоящему, поэтому обе формы дают один и тот же канал. Заодно исправлены два случая, когда один канал мог получить две разные записи в памяти, и опознаются каналы с именами не на латинице.

Per-channel speed memory on YouTube now recognises the channel in every case.

The extension identifies the channel from the author link under the video. It only understood the short form of that link — so when another add-on rewrote it into the full form ("https://www.youtube.com/@channel/videos"), the channel went unrecognised and the feature did nothing at all: the saved speed was never applied and new presses were never recorded. The link is now parsed properly, so both forms resolve to the same channel. Two cases where one channel could end up with two separate memory entries are fixed as well, and handles that are not written in the Latin alphabet are recognised.
